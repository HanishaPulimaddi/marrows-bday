Put Marion's photo or video here.

  marion.jpg   (or .png / .webp)   -> a still photograph
  marion.mp4   (or .webm)          -> a muted, looping clip

Then set the path in  src/vinylContent.ts  ->  centre.src = '/assets/marion.jpg'

Square-ish crops work best: the centre of the record is a circle.
The film strip photos on the right are set the same way, in the filmStrip array.
